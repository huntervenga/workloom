# Measured Graph card geometry

The compiled `223b708` desktop/mobile Graph gate found overlapping task nodes. Their saved coordinates represented the previous 128px card height plus 36px spacing, while real blocked cards reached 190px before zoom. The new blocker button and wrapped project/status text exceeded the fixed Dagre model. Full Graph titles were also previously clamped to two lines. The actual browser evidence remains the RED result in `/private/tmp/workloom-v7-graph-first.log`; source verification below does not replace that browser gate.

## Behavior

Graph cards now show full wrapping title, project/status, archived/blocked labels and the native View blockers control. The shared [node content and box model](../apps/web/src/features/dependencies/GraphNodeContent.tsx) retain the 240px width, 128px minimum height, 10px padding, 1px border and at least 24px blocker control. Height grows with real content. No title clamp, fixed-height clipping or overflow scroll inside the node is introduced.

[GraphView](../apps/web/src/features/dependencies/GraphView.tsx) mounts a bounded measurement host for the authorized Graph node set, including in List mode before the lazy Canvas is opened. The fixed offscreen host has zero outer height and hidden overflow/visibility; it is inert and aria-hidden, has no DOM IDs, public action labels or tab stops, and receives no action callbacks. Its wrappers and the [real Canvas](../apps/web/src/features/dependencies/GraphCanvas.tsx) use the same explicit box styles and content. Handles are absolutely positioned and do not change that box. No extra HTTP read or write is performed by measurement.

The [measurement owner](../apps/web/src/features/dependencies/useGraphNodeSizes.tsx) reads unscaled complete wrapper bounds. Every measurement is tied to actor/workspace/project, roots/depth/Graph sequence, actual task content and locale. Replaced ResizeObserver, font-ready or resize callbacks cannot publish into a new identity. Measurements update only when actual rounded-up dimensions change. Window resize, font loading completion and ResizeObserver events recheck the boxes without polling, frame delays or speculative character-width calculations. The host is removed at the existing Graph access barrier.

Both initial automatic placement and explicit **Apply automatic layout** use those current per-node sizes. Arrange is disabled while current measurements are unavailable. Canvas waits for positions for every node; it no longer invents a separate fixed-height automatic layout. Full saved/moved positions remain the existing overlay, so opening the Graph, loading fonts, resizing or inspecting blockers does not silently move or save a personal layout.

Existing saved positions may overlap enlarged content. A mix of saved positions and generated defaults may also overlap. They are intentionally retained; only fresh automatic arrangement of the complete selected Graph is claimed to separate its measured rectangles. Explicit Arrange creates the existing unsaved layout draft using the real sizes; **Save my layout** remains separate. Hidden saved positions, full-set layout saves, current-source checks, pending/unknown layout commands, resets and departure guards retain their existing owners and behavior. An asynchronous Arrange result from a replaced graph/measurement scope is ignored.

Dagre receives copied width/height labels, so its internal node centers cannot mutate React-owned measurements or overwrite returned top-left coordinates. Measured [Dagre layout](../apps/web/src/features/dependencies/layout.ts) subtracts each node's own half-width/height. Complete rectangles may be translated together into the coordinate boundary; their distances are never compressed. If their full bounding box cannot fit within the existing ±100,000 coordinate range, a localized error keeps current positions/drafts and offers the task list or fewer roots. There is no grid fallback, content truncation or partial coordinate application. The legacy `fitAutomaticPositions` helper and its explicit legacy tests remain separate; production measured arrangement does not use coordinate scaling.
