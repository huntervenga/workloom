# Workloom: памятка команде

Первые действия в английском интерфейсе.
Локальная версия `306ed35` включена. Размещение для удалённой команды проверяется отдельно; [план пилота](84-team-pilot-plan.md).

## Войти и присоединиться

Откройте [Workloom](http://127.0.0.1:4310/app) → **Sign in**.
Первый вход создаёт ваше пустое пространство. Чтобы работать вместе, нужна ссылка приглашения в общее пространство.
Войдите, **снова откройте исходную ссылку** и нажмите **Accept invitation**. Проверьте показанный аккаунт.
В **Members** → **Team access** владелец выбирает роль, нажимает **Create invitation** → **Copy invitation link** и передаёт ссылку лично.
**Remove access** отзывает доступ; для возвращения потребуется новое приглашение. В пилоте задачи общие для workspace.

## Пространство и проект

**Choose a workspace** переключает пространство; **New workspace** создаёт новое. Укажите название и часовой пояс.
В **Projects** выберите проект или нажмите **New project**. На телефоне навигация открывается через **Open menu**.
Для проб используйте свой проект; [демо пяти человек](82-reports-and-five-person-demo.md) оставьте образцом.

## Задачи и карточка

На **Tasks** нажмите **Add task…**, напишите название и Enter. Можно сразу набирать следующую задачу.
Клик по сохранённому названию редактирует текст. Enter сохраняет и продолжает ввод; ⌘/Ctrl+Enter сохраняет без продолжения.
Карточка открывается через действие открытия деталей или свободное место строки. Обычные поля карточки сохраняются автоматически после редактирования.
Общую кнопку Save всей задачи искать не нужно. Комментарии, часы и групповые изменения подтверждаются отдельно.
**Task actions: …** → **Add subtask** добавляет подзадачу. Detail входит в оценку родителя; Additional work имеет отдельную оценку.
Escape закрывает список или редактор.

## Выбор строк и перенос

Кнопка слева выбирает задачу. Shift выбирает диапазон, ⌘/Ctrl добавляет отдельные строки; максимум100 задач.
Когда эта кнопка в фокусе, ↑/↓ перемещают выбор, Shift+↑/↓ расширяет его, Enter открывает карточку.
Панель **Edit selected tasks** предлагает общие изменения; проверьте выбранные строки и нажмите **Apply to selected tasks**.
Для перетаскивания включите **Sort: Manual**. Линия показывает место вставки.
В **Group: Assignee** перенос между людьми меняет ответственного. Подзадача при этом остаётся у прежнего родителя, прошлые часы сохраняются.

## Сроки, доска и метки

**Due date** задаёт срок; **+ Start date** добавляет начало. Выберите даты в календаре или введите их; начало должно быть не позже срока.
На **Board** перенос карточки между колонками меняет статус. В **Timeline** перенос полосы сохраняет даты, а клик открывает задачу.
Timeline показывает зависимости; изменение дат встреч выполняется через календарь встречи.
**Tags** выбирает метки, **Columns** — видимые колонки. Search и Filters скрывают задачи, не удаляя их.

## Планы, часы и отчёты

**Estimate** — оценка работы задачи; недельный личный план — время конкретного человека.
В **Week for hours** нажмите **Choose week** и выберите человека. Проверьте этот контекст перед вводом плана или факта.
В **Week** подготовьте личные планы. **Save my baseline** или **Save project baseline** сохраняет исходный план для последующего сравнения.
Поздние правки не переписывают этот исходный снимок. На первом пилоте планы фиксируем вручную; автоматический фоновый процесс выключен.
Факт0 означает подтверждённый ноль. **Not recorded** означает отсутствие записи — это разные ситуации.
Откройте **Reports**: сравните команду и отдельных людей, перейдите к задачам. **Saved report** выбирает сохранённый отчёт, **Calculate current report** создаёт новый.
Незавершённую работу пока рано считать переоценённой.
Во **Work types** выбирается одна категория на запись часов; Uncategorized тоже входит в итог. Обычные tags могут пересекаться и не складываются в независимые доли.

## Правила поля для владельца

**Columns** → **Team columns** → **Edit field** → **Rules** задаёт срок изменения и лимит на человека для каждой задачи и поля.
Первый ввод тоже считается изменением; лимит не обнуляется по неделям. **Save rules** подтверждает настройки.
**Make owner exception** требует причину и **Apply exception once**. Исключение видно в истории, но не снимает ручную блокировку и защиту исходного плана.
Изменение правил не заменяет ваш черновик. **Replace draft with current rules** заменяет его только по вашему решению.

## Несколько проектов и неизвестное сохранение

Одна задача может показываться в нескольких проектах: название и статус общие, часы не удваиваются. Ограничения связанных строк — в [83](83-task-project-placements.md).
Если результат сохранения неизвестен, используйте предложенный **Retry**/**Retry original**. Повторно создавать задачу, часы или приглашение не нужно.
При конфликте сначала загрузите свежие данные и сравните их с черновиком. Перед reload или сменой аккаунта разберите незавершённые сохранения: черновики хранятся в памяти страницы.

## Начать небольшой пилот

CSV не обязателен. Настройте секции, статусы, метки и типы полей, затем вручную перенесите10 нужных задач с ответственными и сроками.
Старую Asana оставьте справочником; исходные планы фиксируйте сейчас, не придумывая прошлую историю.
