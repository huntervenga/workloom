Продуктовые требования находятся в 01. Документы 02–08 уточняют реализацию и этапность: весь командный пилот из 01 не должен появиться в первой локальной версии. Если конкретные DTO и физическая схема конфликтуют с продуктовым поведением, согласовать исправление до реализации, а не изменять требования молча.

Состояние на 16 октября 2026 года: локально проверены P0 и ограниченный P1a (рабочее дерево до первого коммита); ранние частичные checkpoints исторические и на своё время не были приняты. Полный P1 сверх критериев P1a, P1b–P6, общий Auth, приватные ACL задач/встреч, worker, календарные connectors, production и обновление старых вкладок — будущие и не проверены. Полный MVP и пилот не достигнуты. Доказательства — в 11, локальный quickstart — в корневом [README](../README.md). Маршруты API, схемы, Dockerfile и Railway-настройки за пределами P0 и P1a в документах остаются целевыми интерфейсами. Исходное исследование из Portfolio HQ перенесено в 01; в старом месте оставлен указатель.

Для продолжения разработки читать 02, 06, 09 и 11, затем релевантные разделы 03–05. Путь раннего пилота: P0–P3 → минимальный импорт → P6; P4 и полный P5 не являются обязательной задержкой первой командной недели. Для перехода команды дополнительно обязательны 07–08. Названия библиотек и базовые версии закрепляются lockfile на P0; новые зависимости добавляются по мере появления функции.
