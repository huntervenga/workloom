# Compact Board cards

The [Board card](../apps/web/src/features/task-board/TaskBoard.tsx) keeps its completion control and full task title at the top. The assignee's full name remains visible; its repeated Assignee definition label stays available to assistive technology as an `sr-only` term. The full due-date text and existing Overdue indication share a wrapping footer with the full-text **Change status** action. The status action uses the existing ghost button style and unchanged small control size. Card padding stays at 12px; ordinary vertical row gaps change from 12px to 8px.

Parent links and unavailable-parent information, unknown/meeting/archive/draft badges, missing-assignee/date labels and full original status editors remain present under their existing conditions. An active editor stays in its own full-width block. Long titles, names and dates may wrap; no line clamp, ellipsis, initials-only name or icon-only replacement is introduced. The existing lane sizing and horizontal Board scrolling remain unchanged. Narrow or verbose cards may need an extra footer line rather than clipping content or shrinking the controls.

The parent still owns every callback, command, permission decision, draft and recovery state. Task/lane order, loaded counts, status grouping and completion behavior do not change. Keyboard order remains parent link when present, completion control when supplied, task title, then status action or the active editor. Existing native controls retain Enter/Space activation and visible focus treatment; the status trigger keeps its original task-cell marker and task-title description.
