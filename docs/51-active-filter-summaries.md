# Visible active task-filter summaries

[TaskFilters](../apps/web/src/features/tasks/TaskFilters.tsx) now shows a compact wrapping summary row for selected status, participant, tag and archive conditions even when the Filters panel is closed. Each native button shows its condition and has a full action label, for example **Clear status filter: In progress**. Its X icon is decorative. Clearing one summary changes only that field, preserving literal search input and every other filter. Focus returns to the existing Filters summary, including when the final condition disappears.

Search remains visible in its existing input and gets no duplicate summary or non-search count. The existing Filters count and all-reset control retain their semantics. Participant remains Participant: this existing server filter is not relabeled as the assignee grouping. The row introduces no saved views, requests, URL state, query/controller changes or client-side filtering.

Names come only from the current supplied catalogs. An archived tag already returned in the authorized catalog keeps its existing name and archived suffix. A missing status, participant or tag gets neutral unavailable copy without displaying its ID or guessing a previously seen name. Catalog and locale changes update labels without invoking filter changes. Labels remain full literal escaped text and may wrap; no line clamp or ellipsis is introduced.

New copy lives in auto-discovered [English filterSummary.json](../apps/web/src/i18n/locales/en/filterSummary.json). The [focused component tests](../apps/web/src/features/tasks/TaskFilters.test.tsx) cover individual clearing, unchanged search/other fields, collapsed-panel visibility, full action labels, native Enter/Space and focus return, no duplicate search chip/count, archived/missing catalog and locale updates, literal long names and existing all-reset behavior. Existing tag query tests remain the server-filter/cursor-isolation regression gate. Source verification: TaskFilters and tag-filter-query passed 16/16 tests across two suites; web source TypeScript no-emit and scoped ESLint passed; localization audit passed (201 source files, 2,568 calls, 2,533 English messages). Exact hashes are recorded with the source freeze handoff.

This source slice performs no build, served asset replacement, live browser, runtime, API/database write, commit or deployment. An active filter adds a wrapping row on mobile; compiled checks at narrow widths still need to verify full labels, no page overflow and sensible surrounding control alignment. Source tests do not establish those measured layout properties.
